# GymMonitor 訓練監測（網頁版）

用手機鏡頭在裝置端辨識姿勢，自動計次、分組、計休息，並用紅／藍色在骨架上標示目標肌群（示意）。

- 網址：https://lcfeng1212.github.io/Gym/（GitHub Pages，來源為 `main` 分支的 `/docs`）
- iPhone：用 Safari 開，分享 →「加入主畫面」可當成 App 使用

## 資料夾

| 路徑 | 內容 |
|---|---|
| `docs/` | 網站本體（直接部署） |
| `docs/library.js` | 動作庫（由 `tools/build-library.js` 產生，勿手改） |
| `docs/fedb-steps.json` | Free Exercise DB 英文原文步驟，點開動作說明才載入 |
| `docs/camera.js` | 關節角度、各動作計次規則、動作提醒 |
| `docs/session.js` | 計次狀態機、自動分組、休息計時 |
| `docs/capture.js` | 相機／影片、MediaPipe 姿態模型 |
| `docs/overlay.js` | 紅（主要）／藍（協同）肌群示意疊色 |
| `docs/lib.js` | 動作庫查詢、搜尋 |
| `docs/sw.js` | 離線快取（網站、姿態程式與模型、照片） |
| `docs/app.js` | 介面 |
| `tools/library-sources.js` | 部位分類、截圖動作、日曆動作對應、可計次清單 |
| `tools/fedb-zh-names.json` | Free Exercise DB 876 個動作的繁中名稱 |
| `tools/mine-catalog.js` | 使用者日曆整理出的 95 個動作（無日期） |
| `tools/test/` | 合成關節資料測試 |

## 重建動作庫與測試

```bash
cd tools
npm install
curl -o .cache/exercises.json https://raw.githubusercontent.com/yuhonas/free-exercise-db/main/dist/exercises.json
npm run build
npm test
```

## v8.1 變更（2026-11-20，Claude）

依模擬測試報告，使用者決定執行的項目：

1. 計次穩定性：關節位置平滑；關節短暫看不清楚（3 個畫面內）沿用上一個位置；超過門檻 10 度以上只需 1 個畫面就算到位（快速動作）
2. 組判定：可計次動作（含自動辨識）一定要數到一下才開組；超過「組結束秒數＋4 秒」沒有新的一下也結束這組（畫面抖動時組不會結束不了）；組的結束時間以最後一下為準
   - 代價：沒選動作時，只記滑輪坐姿划船、滑輪高位下拉、啞鈴側平舉，其他動作不記（v8.3 起可在選項開啟試記時間）
3. 訓練選項新增「組結束判定」4／6／8／12 秒（預設 6 秒，原本固定 4.5 秒）；組剛結束時開始的那一下不再被吃掉
4. 正面拍時，彎舉、側平舉、腿彎舉、腿伸展左右分開計次（交替動作），雙手同時做 0.45 秒內合併成一下
5. 門檻放寬：臀推頂端 150→145 度、起始 135→130 度；深蹲蹲低 115→120 度；高位下拉頂端 150→140 度
6. 離線快取：訓練選項「下載離線資料」（姿態程式＋模型約 15–19 MB＋常做動作照片），之後沒網路也能開啟與辨識
7. 日曆動作中 41 個改配「相近動作」照片與肌群，介面標示器材或握法可能不同
9. 小修：休息中暫停時休息時間照實際時間算；報數不打斷動作提醒；可計次動作只記到時間時標「未數到次數，請核對」
