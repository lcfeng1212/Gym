# GymMonitor 訓練監測（網頁版）

用手機鏡頭在裝置端辨識姿勢，自動計次、分組、計休息，並用紅／藍色在骨架上標示目標肌群（示意）。

- 網址：https://lcfeng1212.github.io/Gym/（GitHub Pages，來源為 `main` 分支的 `/docs`）
- iPhone：用 Safari 開，分享 →「加入主畫面」可當成 App 使用

## 資料夾

| 路徑 | 內容 |
|---|---|
| `docs/` | 網站本體（直接部署） |
| `docs/library.js` | 動作庫（由 `tools/build-library.js` 產生，勿手改） |
| `docs/fedb-steps.json` | Free Exercise DB 英文原文步驟，點開動作說明才載入 |
| `docs/camera.js` | 關節角度、各動作計次規則、動作提醒 |
| `docs/session.js` | 計次狀態機、自動分組、休息計時 |
| `docs/capture.js` | 相機／影片、MediaPipe 姿態模型 |
| `docs/overlay.js` | 紅（主要）／藍（協同）肌群示意疊色 |
| `docs/lib.js` | 動作庫查詢、搜尋 |
| `docs/app.js` | 介面 |
| `tools/library-sources.js` | 部位分類、截圖動作、日曆動作對應、可計次清單 |
| `tools/fedb-zh-names.json` | Free Exercise DB 876 個動作的繁中名稱 |
| `tools/mine-catalog.js` | 使用者日曆整理出的 95 個動作（無日期） |
| `tools/test/` | 合成關節資料測試 |

## 重建動作庫與測試

```bash
cd tools
npm install
curl -o .cache/exercises.json https://raw.githubusercontent.com/yuhonas/free-exercise-db/main/dist/exercises.json
npm run build
npm test
```

## v8 變更（2026-11-20，Claude）

動作庫
- 改用 Free Exercise DB（公有領域，876 個動作，附照片、肌群、器材、難度）＋日曆 95 個動作＋截圖動作，合併後 995 個
- 「選擇運動」照截圖架構：全部／最近項目分頁 → 8 個部位 → 部位內搜尋 → A–Z 拼音首字索引
- 搜尋支援中英文、別名（面拉、face pull、俯臥撐→伏地挺身、捲腹／卷腹）
- 動作說明：照片、主要／協同肌群、器材、難度、計次方式、操作要點與來源、拍攝建議、英文原文步驟

計次與分組修正
- 臀推從底部開始時少算一下（N 下只記 N−1）→ 修正
- 自動模式走動、調整器材幾秒就被記成「動作無法確認」一組 → 改為要先完成一下才開組（只記時間的動作不變）
- 關節閃一下看不清楚、左右側偵測跳動就把進行中的次數歸零 → 改為容忍約 0.5 秒並沿用同一側
- 側平舉起始角度太嚴（拿啞鈴手臂自然外開約 25–30 度就不算起始）→ 放寬
- 舊版用名稱規則判斷可否計次，會把「推胸拋球」「頸前臥推」等當成胸推 → 資料庫動作改用明列清單

新功能
- 骨架白色、主要肌群紅色、協同肌群藍色（示意）
- 語音報數、組完成與休息分鐘提示、動作提醒（划船／下拉／引體軀幹晃動、側平舉抬過肩、腿推下放過深等）
- 訓練中螢幕常亮；切到背景改為暫停（原本直接結束）
- 前鏡頭鏡像顯示、模型選擇（輕量／完整）、姿態模型只載入一次（切鏡頭、暫停後繼續更快）
- 紀錄依日期分組、「複製這天」輸出文字（可貼給 Claude 寫入健身日曆）、刪除單組、改名可從動作庫選
- 深色模式、加入主畫面圖示

驗證範圍
